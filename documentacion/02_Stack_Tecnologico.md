# Especificaciones Técnicas y Stack Tecnológico

El proyecto se ha desarrollado bajo los estándares de **Modern Android Development (MAD)**.

## 1. Lenguaje y Plataforma
- **Kotlin 2.4.0**: Uso de corrutinas, Flow y serialización avanzada.
- **KSP2 (Kotlin Symbol Processing)**: Para la generación de código ultra-rápida en Room y Hilt.
- **Jetpack Compose**: UI declarativa para una interfaz reactiva y animaciones fluidas.

## 2. Bibliotecas Core
- **Hilt (Dagger)**: Inyección de dependencias para un código modular y testeable.
- **Room Persistence**: Base de datos SQLite con soporte para búsquedas complejas.
- **Retrofit & OkHttp**: Consumo de APIs REST (Google Books) con interceptores de seguridad.
- **Coil**: Carga eficiente de imágenes asíncronas.

## 3. Inteligencia Artificial y Visión
- **Google Gemini AI (1.5 Flash)**: Generación de resúmenes y análisis de género literario.
- **ML Kit Text Recognition**: Motor de OCR local para la detección de códigos ISBN en tiempo real.
- **CameraX**: Integración nativa del hardware de cámara del dispositivo.
- **Android-Image-Cropper**: Herramienta de post-procesamiento de imágenes.
