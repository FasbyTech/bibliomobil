# Bibliografía y Referencias

## 1. Documentación Oficial
- **Android Developers**: [Guías de Jetpack Compose](https://developer.android.com/jetpack/compose) y [Room Persistence](https://developer.android.com/training/data-storage/room).
- **Google AI**: [Documentación de Gemini API for Android](https://ai.google.dev/android).
- **ML Kit**: [Reconocimiento de texto (OCR) en dispositivos móviles](https://developers.google.com/ml-kit/vision/text-recognition).

## 2. Bibliotecas de Terceros
- **CanHub/Vanniktech**: [Android-Image-Cropper](https://github.com/vanniktech/Android-Image-Cropper) - Licencia Apache 2.0.
- **Square Open Source**: [Retrofit](https://square.github.io/retrofit/) y [OkHttp](https://square.github.io/okhttp/).
- **Coil**: [Image loading library for Android backed by Kotlin Coroutines](https://coil-kt.github.io/coil/).

## 3. Estándares y Metodologías
- **Robert C. Martin (2017)**: *Clean Architecture: A Craftsman's Guide to Software Structure and Design*.
- **Google**: [Guía de Arquitectura de Apps Android](https://developer.android.com/topic/architecture).
- **Material Design 3**: [Directrices de diseño visual y de interacción](https://m3.material.io/).
